# ADR-16 — Oberfläche skalieren wie ein Browser-Zoom

| | |
|---|---|
| **Status** | angenommen, umgesetzt |
| **Datum** | 2026-09-28 |
| **Herkunft** | Wunsch André: „größere Schrift, vielleicht 130 %" |

## Entscheidung

* `ZoomHost` legt eine Skalierungs-Transformation über die ganze Oberfläche.
  Das Fenster behält seine Größe, der Inhalt wird größer und ordnet sich neu an.
* Stufen 80–200 %, **Standard 130 %**. Bedienung: Auswahl in der Tab-Leiste,
  ⌘+ / ⌘− / ⌘0.
* Gespeichert in `~/Library/Application Support/JD-990 Editor/JD-990 Editor.settings`
  (`uiScale`).
* Beim ersten Start wächst das Fenster auf 1320×900 × Zoom, soweit der
  Bildschirm reicht.
* `--testmode` nutzt 100 % (oder `--scale=<n>`) und speichert nichts.
* Passt die obere Leiste nicht in eine Zeile, bricht sie in zwei Zeilen um.

## Verworfene Alternativen

* **`Desktop::setGlobalScaleFactor`** vergrößert auch das Fenster und betrifft
  alle Fenster.
* **Schriftgrößen einzeln anheben** passt nicht zu den Fadern und Grafiken und
  verlangt überall Layout-Pflege.
